# Clinical Translation Review — Worker Web Portal (Marathi, Hindi)

**Status: NOT APPROVED. All 22 entries below are awaiting review by a qualified, native-speaker clinician.**

The HerDoc worker web portal shows clinical guidance in English, Marathi (मराठी) and Hindi (हिन्दी).
The phrases below carry clinical meaning (risk actions, trend warnings, vital-sign names). Their Marathi
and Hindi wording was drafted by the development team and has **not** been checked by a clinician.
Until every entry here is signed off, the translations must be treated as drafts and the portal should
not be used with real patients in Marathi or Hindi.

- Source of truth for the wording: `web/src/i18n/locales/en.js`, `mr.js`, `hi.js`
- Each entry below is marked `// REVIEW` in `mr.js` / `hi.js`. `npm run check:i18n` lists them.
- The English risk actions and trend messages come from the mobile risk engine
  (`mobile/app/services/trend_engine.js`); `npm run check:i18n` fails if the web English text drifts from it.
- Translation changes only what is displayed. Risk thresholds, the model, stored records, API values and
  risk codes (green / yellow / red) are not affected by any wording decision here.

## How to review

For each entry, record the reviewer, qualification, language, date and a decision:

- **Approved** — the current wording is clinically accurate and clear for health workers.
- **Revision needed** — write the corrected wording in "Revised wording" and explain why in "Notes".

Please also answer the terminology questions in the next section; several unflagged lines must follow
those decisions so the interface stays consistent.

## Terminology questions for the reviewer

1. **Heart rate vs pulse (entry 11).** The reading is labelled "Heart rate (bpm)" in English. The drafts use
   different terms in different places:
   - Marathi: label and error message say "नाडीचे ठोके" (pulse beats); the visit history line says "नाडी" (pulse).
   - Hindi: the label says "नाड़ी / हृदय गति" (pulse / heart rate), the error message says "हृदय गति"
     (heart rate) and the visit history line says "नाड़ी" (pulse). **Three different terms for one reading.**
   - Question: is the value field workers record a pulse rate or a heart rate, and which single term should
     be used everywhere?
2. **The word for "visit" in Hindi.** Hindi uses "जाँच" (check-up / test) for "visit" (visit history, record a
   visit, "last 3 visits") and also in the yellow action "दोबारा जाँच करें" (check again). A reader may not
   be able to tell whether "जाँच" means a home visit, a clinical examination or a laboratory test.
   Marathi uses "भेट" (visit) and "तपासणी" (examination) separately. Is a distinct Hindi word for "visit"
   (for example "मुलाक़ात" or "दौरा") preferable?
3. **"your last 3 visits" (entries 5–7).** The English source, generated by the mobile risk engine, says
   "your last 3 visits" although the message is shown to the health worker about a patient. The drafts
   say "the last 3 visits" instead. Confirm this is acceptable. (Changing the English source would require
   a change to the mobile engine and is out of scope for this review.)
4. **"Refer" (entries 4 and 8).** Marathi uses the formal "संदर्भित करा / संदर्भित केले"; Hindi uses the
   English loanword "रेफ़र करें / रेफ़र किया गया". Which wording will health workers understand and act on?
5. **Systolic / diastolic (entries 9–10).** Both languages transliterate "सिस्टोलिक / डायस्टोलिक". Formal
   native terms exist but are less familiar in the field. Confirm which is clearer for health workers.
6. **"PHC" (entry 4).** The translations add an expansion in brackets (प्राथमिक आरोग्य केंद्र /
   प्राथमिक स्वास्थ्य केंद्र) that the English text does not have. Confirm this is wanted.

## Applying an approved review

1. Only after a decision is recorded in this file with the reviewer's name, qualification and date:
   update the wording in `web/src/i18n/locales/mr.js` or `hi.js` (and the related lines above).
2. Remove the `// REVIEW` marker only from entries marked **Approved**.
3. Run `npm run check:i18n` and `npm run build` in `web/`; both must pass.
4. Commit the locale change together with this file so the approval and the wording change are reviewed together.
